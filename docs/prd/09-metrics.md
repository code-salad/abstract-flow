# 9. Success metrics

| Metric | Target (MVP, 90 days post-launch) |
|---|---|
| Time-to-first-flow on cold repo | < 2 min (100k LOC) |
| Task success: new user answers "what does this endpoint do on failure?" correctly | ≥ 80% in moderated tests, vs. ≤ 50% baseline reading code raw |
| Call-resolution accuracy (resolved call sites resolving to the correct target) | ≥ 99% on benchmark repos; unresolved sites flagged, never wrong |
| Weekly retention among activated users (viewed ≥ 3 flows) | ≥ 30% |
| Correctness bug reports (an edge shown that doesn't exist) | 0 tolerated — treated as P0 |
